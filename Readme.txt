You can turn a ListView into an Explorer-like component (similar to ShellListView) by using the procedure ListViewAsExplorer(LV: TListView; APath: string; AShowHiden: Boolean = False);

Сделать из ListView проводник а-ля ShellListView можно с помощью процедуры procedure ListViewAsExplorer(LV: TListView; APath: string; AShowHiden: Boolean = False);
